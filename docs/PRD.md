# ConstructAI — Product requirements

Source: owner-approved ConstructAI PRD in the planning conversation; this repository baseline consolidates its requirements into stable IDs (see requirements/TRACEABILITY.md). Original independent construction ERP inspired by industry problems, not a clone of proprietary code, branding or UI.

## Product and users
Unify construction projects, vendors, customers, estimates, purchase orders, contracts, invoices, budgets, payments, documents and operational workflows. Users: contractors, subcontractors, owners, project managers, finance managers, accountants, team members, viewers. Reduce manual entry, delays, missing documents and budget surprises. Measure actual extraction accuracy, processing time, duplicate precision/recall, financial balances, budget variance, workflow completion, AI latency/token usage/cost when configured, failed jobs and approval turnaround. Never invent metrics.

## Scope
P0: auth, organizations/RBAC, dashboard, projects/vendors/customers, payable invoices, document extraction/validation/duplicates, approvals, Atlas/RAG, queues, notifications, audit, tests. P1: receivables, estimates, contracts, POs, budgets, payments, tasks, reporting, automations, eval dashboard. P2: simulated email ingestion, advanced OCR, specialized agents only when justified, compliance, mock accounting, forecasting/custom reporting, advanced workflows, optional local model. No cloud deployment, Kubernetes, live banking/payments/accounting/email, legally binding e-signatures, statutory accounting compliance, mobile-native apps or model training.

## Requirements
- **R00 Foundation:** pnpm/Turborepo, strict TS, Next App Router, Nest API, independent BullMQ worker, local Supabase PostgreSQL/Auth/Storage, Prisma, pgvector, Redis, env validation, Swagger, lint/format, Jest/Vitest/Playwright, local setup, synthetic seed, docs. Local Docker only for infrastructure. Ollama optional. No Python unless documented need. Health/readiness check DB, Redis, storage, worker heartbeat, optional AI.
- **R01 Identity:** signup/login/logout/reset/session refresh, profile, protected routes, onboarding/create or join organization, local email invitation and organization switch; roles owner/admin/project manager/finance manager/accountant/member/viewer. Central permission matrix and project/resource scope; membership checked server-side. User can have different roles across organizations.
- **R02 Tenancy:** UUIDs, tenant IDs and composite constraints, tenant-scoped SQL/Prisma, storage, cache, queues, vector queries, conversations/checkpoints/reports. RLS on exposed tables; no privileged frontend keys or user-editable metadata authorization. Separate Supabase system schemas from app migrations; one migration authority. Tests Org A vs B, role denial and unauthenticated access.
- **R03 Core ERP:** project CRUD with code, dates, location, manager/customer, contract value/budget/status (draft/planning/active/on hold/completed/cancelled), archive history; project detail overview/tasks/budget/invoices/expenses/vendors/contracts/docs/team/activity. Tasks assigned, due, priority/status/comments; vendor/customer contacts, address, tax ID, payment terms, currency, insurance expiry, status/notes; duplicate suggestions never auto-merge.
- **R04 Finance:** invoice AP/AR with vendor/customer, project, PO, number, dates, currency, subtotal/tax/discount/total, paid/outstanding and line items (quantity, unit, rate, tax, cost allocation). Separate extraction/approval/financial states (draft/open/partial/paid/void; overdue derived). CRUD draft, review, submit, approve/reject/correct, void, payment record, export/PDF and audit. Monetary decimal/minor units, deterministic validation, transactional payment allocation, no overpayment, no duplicate postings or silent historical edits, no mixed currency totals without conversion. No money movement.
- **R05 Documents:** private PDF/JPEG/PNG upload with actual MIME, limits, checksum, tenant access, versions, categories/tags, preview/download, archive/search. Queue text extraction, OCR fallback, classification, structured Zod extraction of vendor/invoice/dates/currency/PO/project/line items/tax/total/terms, source evidence/page/missing/validation/review flags. Match vendor/project; exact checksum and vendor/invoice number plus similarity/date/amount for suspected duplicates. Split-screen preview/edit/validation and human review. Retry/restart safe, original preserved, no duplicate drafts, clear failure states.
- **R06 Approvals:** invoice/PO/estimate/budget/AI/workflow/correction request; pending/approved/rejected/changes requested/cancelled/expired/executed/failed states. Immutable proposal payload hash/version, reviewer permission, expiry, separation of duties, notifications, reject or request changes, revalidate after review; concurrent/retried approvals cannot repeat business effects. Append audit events with actor, resource, changes, request/execution IDs, outcome; no sensitive secrets.
- **R07 Dashboard:** actual DB KPIs (project value, expenses, receivables/payables, overdue, balances, budget, approvals, active/completed projects, tasks, jobs), charts (cash flow, revenue/expense, budget vs actual, status, project progress), filters/date/project, recent activity, deadlines and drill-downs. Avoid double counting commitments vs actuals; defined status/currency aggregation.
- **R08 RAG:** versioned chunking with page/section metadata, configurable 500–800 tokens and 50–100 overlap baseline; embeddings provider/model/version/dimension and reindex strategy; tenant/resource-filtered pgvector + keyword search, bounded context, citations with authorized links/page/excerpt, optional rerank justified by eval. Archive/replace removes stale search results; abstain if insufficient evidence. Financial totals from typed deterministic services not RAG.
- **R09 Atlas:** streaming chat with threads/history, stop/retry, Markdown sanitized, source links/cards, tool status and approval UI. Provider adapters mock/OpenAI/Gemini/Ollama, configurable chat/extraction/embedding, bounded retries/timeouts/cancellation, usage/cost only when known; external disabled unless user opts in. Read tools projects/budgets/expenses/vendors/invoices/overdue/financial summary/approvals/docs/deadlines/reports; action proposal tools task/invoice draft/estimate/reminder/document/workflow. Trusted context outside model; validate schemas, authorize per call, no arbitrary SQL; never claim success without tool result.
- **R10 Agents:** LangChain.js/LangGraph.js typed state, persisted tenant-scoped PostgreSQL checkpoints, bounded steps/tools/tokens/time, interrupt/resume, revalidate action and permission, idempotency key, audit. Start one assistant plus tools; finance/project/knowledge/document/automation subgraphs only with justified complexity. Treat retrieved content as untrusted, reject injection, never allow AI to self-approve or override finance rules.
- **R11 Automation:** domain events, transactional outbox, durable BullMQ queues (document, classification/extraction, embeddings, automations, outbox, notification, reports, mock integration), minimal payload, retry/backoff/failure inspection, progress, graceful shutdown. Versioned workflows trigger document/invoice/project/budget/contract/schedule/manual; conditions/actions process, notify, report, draft reminder/task, request approval, summarize/extract. Bounded recursion; execution history. Simulated external actions only.
- **R12 Extended ERP:** AR issue draft PDF/partial payments; estimates labor/material/equipment/subcontractor/overhead/markup/tax, version, lifecycle, accepted converts to project, no invented prices; contracts version/parties/date/amount/status, evidence-backed summary/clauses/payment/deadlines; POs line items/vendor/project/approval/delivery, matching invoice variance; budget labor/material/equipment/subcontractor/transport/permits/admin/other, planned/committed/actual/remaining/variance/utilization, threshold alerts. Local notification/email simulator, mock accounting and compliance.
- **R13 UI:** premium responsive enterprise SaaS, accessible contrast/keyboard, slate/navy and teal/emerald, light/dark, sidebar, org switch, breadcrumbs, global search, notifications/profile/Atlas, tables/filters/pagination/forms/dialogs/status/chart components and real loading/empty/error/success. Public auth/onboarding and protected dashboard, projects/tasks/vendors/customers, invoices/review/receivables/estimates/POs/budgets/payments/contracts, documents/processing, assistant/thread, approvals, workflows/executions, reports/activity/notifications, settings and admin jobs/audit/evals. Hide unavailable modules; no fake buttons.
- **R14 APIs:** /api/v1 REST + OpenAPI, auth context, organizations/members/invites, projects/tasks/budgets/activity, vendors/customers, invoices/validate/submit/void/payments/history, document upload/download/status/extraction/retry/search/archive, approvals approve/reject/change/cancel, AI chat/conversation/cancel/executions/usage, workflows enable/disable/run/executions, reports/dashboard/aging/budgets, notifications/audit/jobs/health. Typed DTOs, pagination/filter/sort, request IDs, consistent errors, rate limits, idempotency for writes.
- **R15 Security/reliability:** JWT verification, resource RBAC, RLS and DB constraints, SQL/XSS/CSRF/CORS/SSRF defenses, secret handling, uploads, no stack traces, structured logs and request correlation, local AI traces (no hidden reasoning), immutable audit, health checks, retry/recovery, no real sensitive data in Git.
- **R16 Evaluation/testing:** unit financial math/validation/permissions/state/duplicates/budgets/tools; integration DB/auth/tenant/upload/queue/outbox/checkpoints/approval races; Playwright onboarding/project/invoice/duplicate/Atlas/RAG/approval/tenant. Held-out synthetic evaluation fixtures digital/scanned/missing/wrong totals/duplicates/adversarial docs and tenant attacks; deterministic extraction field accuracy, retrieval precision/recall/citations/abstention, agent tool/args/task/approval/injection/step limits. Mock results not real model accuracy.
- **R17 Local demo:** two fictional orgs, six+ role accounts, 8–12 projects, 15–20 vendors, 10 customers, 30–50 invoices, 10 estimates/POs, 8 contracts, 30 tasks; realistic statuses, actual synthetic PDFs/images, demo guide and local credentials. Demo flow auth→org→project/budget→vendor→upload→extract/review→approval→financial dashboard→contract RAG→Atlas overdue/budget→propose task→approve→audit→org isolation.
- **R18 Advanced:** optional local model, simulated email ingest, advanced OCR, specialized agents only with evidence, compliance, forecasting and custom reports, workflow builder. Defer until P0/P1 pass.

## Data model families
Identity UserProfile, Organization, Membership, Role, Permission, RolePermission, Invitation, Settings; Project, ProjectMember, Task, Comment, Milestone, Budget, BudgetItem, CostCategory, Expense; Vendor/Customer/contacts; Invoice/LineItem, Payment/Allocation, Estimate/LineItem, PO/LineItem, Contract/Version; Document/Version/Extraction/Chunk/Tag/ProcessingRun; Conversation/Message, AIExecution/ToolExecution/Usage/EvalDataset/Case/Run/Result; ApprovalRequest/Decision/ActionExecution; Workflow/Version/Trigger/Step/Execution/StepExecution, OutboxEvent, ProcessedEvent, IdempotencyRecord; Notification, AuditLog, IntegrationConfiguration/Execution. Design normalized schema incrementally, UTC timestamps, date-only business dates, indexed tenant keys, foreign keys, archive as required.

## Definition of done
Real persisted behavior, authorized API/UI, error/loading states, applicable TDD/tests and security checks, exact-head verification evidence, independent review where available, updated docs. No unresolved Critical/Important findings. Local readiness is not commercial production readiness. No later milestone before integration and closeout of current milestone.
